# CineLux Custom v0 — дополнения по решению пользователя (21.10.2026)

**Статус: только проектирование и подготовка исходных файлов, сборку / IMG / PKG / OTA НЕ запускать.**

## Разделение устройств и пользовательский брендинг

| Hardware ID | Бренд устройства в UI | Модель в UI | Штатная база проверенного образа |
| --- | --- | --- | --- |
| 8052, 1 HDMI | Everycom | CineLux 4K | RUIOS.8052.1.0.4, октябрьская OTA |
| 8054, 2 HDMI | FlixTone | D11 Master | RUIOS.8054.1.0.1, сентябрьская factory PKG |

Проект общих пользовательских изменений можно назвать MT9660 Custom, но в Settings -> About устройство должно иметь **соответствующее** имя производителя. Отображаемая версия кастома — отдельная строка (например, Custom v0), штатный номер базовой прошивки — отдельная строка. Не подменять ro.product fingerprint/board ID/security patch/Android version только ради UI. Это не разрешает кросс-прошивку 8052↔8054.

## Очистка демонстрационного и рекламного ПО

Обязательная цель: убрать ZXStore, рекламу/вызовы магазина из ZEASN и заменить заводской HOME на проверенный FLauncher с резервным HOME. Отдельно **проверить**, прежде чем удалять: RetailDisplay, TrdDreamPic, VendorDisclaimer, WFDSinkTest, FTAirplayWireless, UI-модули демо. Не вырезать пакеты по одному только названию. VendorDisclaimer может понадобиться SetupWizard; кастинг AirPlay/Miracast — реальная пользовательская функция.

## Bluetooth

По решению пользователя **в v0 сохранять RJBluetoothSpeaker / Bluetooth A2DP Sink**, пока не подтверждена его изоляция и пользователи не получили опциональное отключение функции. Обязательно сохранить Bluetooth-пульт, pairing/AutoPair, A2DP-выход на наушники/акустику. Удалять sink по умолчанию запрещено.

## Ожидание/заставки для 1LCD

Предпочтение: при наличии OEM idle demo, idle picture, Android Daydream или программного dimming **не использовать декоративную заставку и не запускать искусственное затухание/чёрный экран**. Проверить, что действительно реализовано в устройстве и можно ли штатно отключить. Не отключать thermal trips/PMU/LED overheat protection/охлаждение/штатное отключение питания/энергетическую безопасность. Не путать безопасный idle policy с защитой от перегрева.

Проверить по ADB: `dumpsys dreams`, `settings get secure screensaver_enabled`, политику DreamManager, живые receiver/service TrdDreamPic/RetailDisplay, PowerManager/sleep. Пробное `settings put secure screensaver_enabled 0` только после подтверждения, что это нужный toggle и приложение имеет необходимые права.

## Developer options

По желанию пользователя пункт Developer options должен быть видим по умолчанию в первой версии. Для Android 13 кандидат: `settings put global development_settings_enabled 1` при инициализации после первого provision, если настройка подтверждается на устройстве. **Это не означает** автоматически включённые ADB по сети или USB debugging, root, userdebug, отключённый SELinux либо отключённую проверку подписи. Доступ к разделу Settings проверить. Не редактировать ro.debuggable/ro.secure и не делать публичную прошивку с открытым сетевым ADB.
