# RUIOS 8052 и 8053 — проверка каналов, OTA и связь с Everycom / FlixTone

Дата исследования: 20 октября 2026. Исходники: официальные доступные по URL OTA-индексы и оригинальные ZIP из релиза **OTA_Updates** в этом репозитории.

## Что доказано

| Параметр | 8052 | 8053 |
|---|---|---|
| Канал OTA | `RUIOS.8052.1.0.4` | `RUIOS.8053.1.0.0` |
| Сборка Android | `eng.suhaix.20261012.025220` | `eng.luzhih.20260612.083454` |
| Дата сборки | 12.10.2026 | 12.06.2026 |
| Android | 13, SDK 33 | 13, SDK 33 |
| Тип / подпись сборки | userdebug/test-keys | userdebug/test-keys |
| Предназначенный Android device | mt5873 | mt5873 |
| Формат OTA | Android A/B `CrAU`, `payload.bin` v2 | Android A/B `CrAU`, `payload.bin` v2 |
| Шифрование OTA | Не обнаружено: разделы полностью восстановлены | То же |
| Подпись метаданных payload | RSA-2048/SHA-256, успешно проверена | То же |
| Сертификат | Совпадает с официальным AOSP testkey.x509.pem | То же |

**8052**: код `8052` присутствует на фотографии системной версии `20260805_8052_c4c2d0ac` у проектора Everycom с 1 HDMI. Точная сборка из OTA `eng.suhaix.20261012.025220` совпадает с октябрьским фото AIDA64. Это надёжная связь канала 8052 с данным реальным проектором.

**8053**: содержимое соответствует гораздо более ранней июньской прошивке, но **никакого подтверждения связи с FlixTone D11 Master нет**. В D11 на фотографии — `eng.suhaix.20260905.031903`. Номер 8053 может обозначать другую OEM-платформу, ревизию, бренд или регион; это только гипотезы.

Слово `mt9660` в URL, по-видимому, обозначает серверный каталог семейства TV SoC. Поля реальных OTA `pre-device=mt5873` и `ro.build...` указывают `mt5873_cd`. Нельзя автоматически считать оборудование MT9660 только из-за URL.

## Поиск других OTA-каналов

Проверены публичные JSON по схеме `/ota/android/mt9660/{ID}/{ID}_ota.json` для всех номеров **8000–8100**, с паузами между запросами. Найдены только **8052** и **8053** (HTTP 200); остальные **99** адресов вернули HTTP 404, включая 8054. За пределами этой схемы или диапазона могут быть другие номера.

## Содержимое и сравнение

- OTA архивы распакованы; `payload-dumper-go` реконструировал реальный `boot`, `dtbo`, `tvconfig`, `tvservice`, `product`, `system`, `system_ext`, `vendor`, `vbmeta` и прочие разделы.
- В Android EROFS-деревьях: 3 941 одинаковых путей; 2 155 файлов идентичны, 1 786 файлов имеют иной SHA-256, по 8 уникальных путей в каждой версии.
- `KuSourceRJ` версии 5.3 против 3.6, `zxlauncher` 2.0.43 против 2.0.37. `KuSettings` 1.0 и `RuiAutoFocus` 4.2 в обеих версиях, но файлы различаются.
- `KuSetupWizard` найден в 8052, `Provision` — в 8053. Это не доказательство определённого количества HDMI: состав APK меняется и между поколениями прошивок.
- Августовская заводская PKG для 1 HDMI использовала `eng.luzhih`, сентябрьская PKG для 2 HDMI — `eng.suhaix`. Это сильный сигнал общего OEM проекта, но даты и названия сборочных учётных записей сами по себе не идентифицируют PCB.

## Подписи: важное различие

1. **A/B OTA контейнер:** оба `payload.bin` имеют настоящие RSA-2048/SHA256 подписи метаданных, математически проверенные сертификатом из ZIP. Этот сертификат побайтно совпадает с публичным AOSP testkey. Стандартные тестовые ключи AOSP доступны для тестовых сборок, так что подписание собственного OTA **в принципе технически доступно**.
2. **Android Verified Boot:** в ранее исследованных *заводских PKG* `vbmeta_a` и `vbmeta_system_a` использовали SHA256_RSA4096 с другим публичным ключом. Наличие тестового сертификата OTA **не позволяет** подменять содержимое разделов на устройстве с включённым AVB и заблокированным загрузчиком.
3. **Приёмка OTA:** наличие корректной подписи пакета само по себе не означает, что OEM-клиент, `update_engine`, загрузчик и аппаратная конфигурация примут кастомный образ. Требуются проверка текущего состояния загрузчика и безопасный способ восстановления, прежде чем испытывать обновление на реальном проекторе.

## Вопрос совместимости

Оба OTA имеют одинаковое `pre-device=mt5873`. Это *недостаточно строгий аппаратный идентификатор*: совпадение чипа не гарантирует совместимость моторного контроллера, HDMI, камеры/ToF, DTBO, звуковых и заводских калибровок.

**Не пытаться кросс-прошивать** 8052/8053 на FlixTone D11 или иную ревизию только из-за совпадающего `mt5873`.

## Как узнать точный RUIOS-канал FlixTone D11

Предпочтительно посмотреть меню «Версия системы» (OEM-настройки) на D11: у Everycom оно выводило `20260805_8052_c4c2d0ac`. Можно дополнительно запросить через ADB список безопасных системных properties и вывод `RuiYunOta`, не вскрывая привилегированные данные и не запуская установку.

Если там обнаружится `8053`, гипотеза о связи с этим каналом получит подтверждение. Пока — нет.
