## Android bootanimation и различие этапов

В `8052.1.0.4` в извлечённых system/product не найден `bootanimation.zip`; обнаружены `system/bin/bootanimation`, `libbootanimation.so`, `init/bootanim.rc`. Это доказывает наличие системного компонента, но не наличие мультимедийной анимации Android: стандартный сервис может показывать fallback, а первая картинка `boot0.jpg` отображается до него.

**Ни один из файлов не является GIF.** `boot0.jpg` — статические JPEG и `boot0.mp3` — музыка. Запись/воспроизведение по факту boot пока не проверены.

## Как менять в будущей прошивке, НЕ сейчас

1. Определить на реальном проекторе последовательность: early splash `boot0.jpg` → Android boot animation → launcher, и проигрывается ли `boot0.mp3`.
2. После решения пользователя о дизайне сохранить разрешение и формат оригинального `boot0.jpg`; одновременно обновлять связанные копии `tvconfig` и `bootdata`, только если подтверждён активный путь.
3. Сначала искать настройку отключения проигрывания `boot0.mp3`; при отсутствии такого механизма обсуждать корректный бесшумный MP3, совместимый с декодером (не просто удалить файл, не подтвердив обработку отсутствия).
4. Следить за отдельной первичной заставкой и boot animation Android: смена `system/media/bootanimation.zip` не заменяет splash в `tvconfig/bootdata`.
5. Изменять оригинальные разделы только при подтверждённом AVB/recovery/rollback. Первый пакет `custom-v0` без bootdata/tvconfig; кандидат в следующую ревизию.

Примечание: оригинальные двоичные разделы `bootdata_a`/`tvconfig_a` различаются между платами, запрещено копировать целый раздел одной ревизии на другую только ради logo. Нужно изменять отдельный файл в исходном разделе соответствующей платы.
